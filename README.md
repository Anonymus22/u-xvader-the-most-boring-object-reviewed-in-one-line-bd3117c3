# The Most Boring Object, Reviewed in One Line

A one-line review of the dustpan — the dullest everyday object I could name,
and the one whose single flaw everyone recognises: no matter how carefully you
sweep, it always leaves a thin line of dust behind, as if it were saving some
for later. The program writes that line, and only that line, to
`/output/entry.txt`.
